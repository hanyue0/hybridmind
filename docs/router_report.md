## 已知局限

1. **阈值在 OOF 上选取，再用于同一批 OOF 评估，存在轻度乐观偏差**；更严谨的做法是留出独立测试集，样本量足够后补做。
2. 160 条样本偏少，AUC 的置信区间较宽（可用 bootstrap 估计，待补）。
3. 特征全部来自题面文本，不含对话历史；多轮场景需要另加状态特征。
