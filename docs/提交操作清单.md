## 三、可选：换真人配音

现在这版是机器配音（edge-tts）。要换的话：

1. 按 [`../../预指导后修改/11_配音稿.txt`](../../预指导后修改/11_配音稿.txt) 录 6 段，
   放 `D:\桌面\AMC-传智\配音\v2\真人\`，命名 `seg1.mp3` … `seg6.mp3`
2. 告诉我，我跑：

```bash
python scripts/assemble_v2.py --audio "D:/桌面/AMC-传智/配音/v2/真人"
python scripts/subtitle_v2.py --burn
```

画面会按新音轨自动重排，字幕重新对齐（whisper 逐词时间戳 + difflib 强制对齐），
两条命令，不用手工调时间码。
