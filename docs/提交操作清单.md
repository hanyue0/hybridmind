## 三、可选：换真人配音

现在这版是机器配音（edge-tts），可以听但不如真人。要换的话：

1. 按 [`docs/tech/video_script_v2.md`](tech/video_script_v2.md) 录 6 段，放 `D:\桌面\AMC-传智\配音\v2\`
2. 告诉我，我跑：

```bash
python scripts/assemble_v2.py --audio "D:/桌面/AMC-传智/配音/v2"
python scripts/subtitle_v2.py --burn
```

画面会按新音轨自动重排，字幕也会重做——两条命令，不用手工调时间码。
